THREE-IN-ONE / STATUS ICON PURE CSS · MOTION STUDY 001

Three signals. One clear view.

Battery, Wi-Fi, and cellular signal—unified.

Reduced motion is enabled by your system preference; showing a static icon.

01 /

The outer ring is battery

A conic gradient and ring mask create the open-bottom battery arc. Changing the angle makes the charge cycle up and down.

02 /

The center is Wi-Fi

Two concentric arcs and a solid bottom sector form an upward-opening quarter circle. Shifting brightness demonstrates connection strength.

03 /

The four dots are cellular

Four dots follow the bottom arc, fading and brightening in sequence. More illuminated dots indicate a stronger signal.

Built with HTML and CSS only; cycles every 8 seconds. This is a web simulation, not live device data, and it does not modify the iPhone status bar.
